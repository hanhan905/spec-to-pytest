## Failures observed and addressed during implementation

- Added app-boundary regressions first exposed the missing isolated application factory.
- The inherited Ruff exclusion configuration incorrectly included disposable dependencies. The
  task-local environment/cache was affected, not the original/global environment. Exclusions were
  corrected and dependencies restored from a fresh cache before subsequent validation.
- An early browser run preceded browser installation: 4 API passes and 9 setup errors. After the
  matching browser finished installing, the suite passed. Those errors were never labelled passed.
- The initial runner lacked early plugin option registration and returned blocked; it was fixed.
- Streamed oversized requests initially returned 400 through the parser. The bounded receive layer
  was corrected and its 413 regression passed.
- Restart validation exposed TIME_WAIT being mistaken for an active port owner. SO_REUSEADDR fixed
  that case while the separate occupied-listener test still rejects unrelated services.
