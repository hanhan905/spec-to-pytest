# Provenance and distribution boundaries

This independent working repository starts from the owner's local Playwright practice framework
and AI-testing demo (source checkpoint `28a0f59` plus separately reviewed working assets).
The original directories and their Git histories are retained, not rewritten or published here.

Retained building blocks: Python Page Objects and workflows, dashboard teaching page, community
HTML/CSS, baseline UI/API checks, basic result utilities and synthetic demonstration accounts.

New or substantially revised work includes isolated application construction, SQLite persistence,
bounded and metadata-stripped media storage, opaque sessions, test-control authorization, owned
service lifecycle, version-2 contracts, explicit case mappings and evidence reconciliation.
This work was developed with AI assistance; maintainers remain responsible for reviewing it.

The workflow is inspired by [Luo Ziyu's TRAE testing article](https://www.infoq.cn/article/JF6Arq1sbXBHKeE747bk).
This is not the author's official repository. It preserves the exploration-to-code concept while
adding frozen plans, earlier data expansion and evidence checks. No article images or long prompt
blocks are redistributed. Third-party tools are installed through dependencies, not vendored.

License selection and final source/asset review are pending. No license is inferred for material
whose redistribution rights have not been established. A clean history does not erase attribution.
