# 场景：内容发布后的完整互动链路

## 目标

验证已登录用户发布一条图文内容后，可以通过标题、正文或标签搜索到该内容，并能完成
点赞和评论；同时覆盖主要边界、异常、权限和状态一致性风险。

## 主链路

1. 使用 `admin / admin123` 登录；
2. 发布标题为“我的AI测试实践”的内容；
3. 正文为“用 Playwright MCP 生成可执行测试，并保留完整证据。”；
4. 标签为“AI测试, Playwright”；
5. 回到内容广场并搜索刚发布的内容；
6. 点赞，验证按钮状态和计数；
7. 评论“这是自动生成后的验证评论”；
8. 验证评论内容和评论计数；
9. 刷新页面后再次验证内容、点赞和评论状态。

## 生成要求

- 生成 8～15 条候选用例；
- 至少包含正常、边界、异常、权限、搜索和持久化；
- 优先自动化可通过本地测试站确定性验证的用例；
- 不在场景中添加真实外部网站、真实社交账号或生产操作；
- 全部候选用例自动执行并保留结果，不等待人工确认。
